# Aktivita: Tutoriál – Poďme otestovať náš prvý program

Rozpoznávanie obrazu je oblasť umelej inteligencie, ktorá zaznamenala značný rozmach. V tomto tutoriáli otestujeme rozpoznávanie obrazu a natrénujeme program na rozpoznávanie psov a mačiek. Následne nám tutoriál pripomenie, že tento program dokáže robiť len to, na čo bol natrénovaný, a teda sa dá aj oklamať.

Tutoriál obsahuje 7 veľmi krátkych výukových videí a môže sa používať pri práci so žiakmi SŠ alebo 2. stupňa ZŠ.

**_Poznámka č. 1:_** Tento výukový program neukladá žiadne osobné údaje. Obrázky sa spracúvajú lokálne na počítači používateľa. Je kompatibilný s prehliadačmi Edge, Chrome, Mozilla, Safari a Opera.

**_Poznámka č. 2:_** Tento výukový program navrhuje stiahnuť si vlastné obrázky na experimentovanie so strojovým učením a fungovaním dátových súborov na trénovanie algoritmu. Ak ale chcete, môžete si stiahnuť aj tieto dva predpripravené dátové súbory:

- Stiahnite si [súbor obrázkov Charlesa Dickensa](Images/Images-set-of-Charles-Dickens.zip)  
- Stiahnite si [súbor obrázkov Williama Shakespeara](Images/Images-set-of-William-Shakespear.zip).


A môžeme sa pustiť do trénovania umelej inteligencie!
